# knittda — Grafana OnCall(IRM) Integration 템플릿 (Jinja2)
#
# ⚠️ OnCall 템플릿은 Jinja2 문법이다(Grafana Alerting 의 Go 템플릿과 다름).
#    데이터는 payload = Grafana Alerting webhook. 주요 필드:
#      payload.status                     firing | resolved
#      payload.commonLabels.alertname     알림명 (그룹 공통)
#      payload.commonLabels.severity      critical | warning
#      payload.alerts[]                   개별 알림 배열
#        .labels.{alertname,severity,slot,env}
#        .annotations.{summary,description,runbook_url,dashboard_url}
#        .startsAt / .generatorURL
#
# 적용 위치: Alerts & IRM → IRM → Integrations → knittda → Templates(연필) → 각 필드에 붙여넣기.
#   Slack 메시지의 Ack/Resolve/Silence 버튼은 OnCall 이 자동으로 붙인다(템플릿으로 못 바꿈).
#   Slack 은 <URL|라벨> 링크·*굵게* mrkdwn 지원. 메시지 시각은 Slack 이 자동 표기(보는 사람 로컬 TZ)라 본문에 안 넣음.
# ─────────────────────────────────────────────────────────────

{{ payload.status == "resolved" }}
